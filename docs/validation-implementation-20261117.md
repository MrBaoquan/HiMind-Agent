## 已实现

- `verify.ps1` 默认 `affected`，`-BaseRef` 选择整项任务的累计差异；`-Explain` 输出逐文件理由和实际计划。说明、UI、适配器、Rust 模块/调用方及构建脚本分别选择检查；未知影响扩大验证。
- 说明文件不启动应用工具链；UI 不自动触发 Rust 全测；构建脚本调用隔离夹具。`quick` 保留综合检查及依赖/dist 损坏修复。Rust 测试仍串行。
- 纯测试身份排除提交号和说明文件，保留其余源码、测试、工具及相关前端输出；构建身份继续包含嵌入提交号。复用保留原始执行收据和 SHA-256，缺失/篡改/失败不可复用。步骤输出摘要在同一轮传递，减少重复扫描。
- 本机 `local` 只接受 UI/VS Code 适配器与白名单说明文件差异。完整 candidate 基线须有匹配源码清单，工具、配置、Runtime 和渠道一致；不允许 Rust/脚本差异或 local 链式基线。
- local 明确 `full_tests=false`，引用完整基线的 Rust 覆盖，核验当前前端/适配器与新二进制。只有 deploy-local 接受 local 收据；正式打包仍要求完整 candidate。缓存回收保护安装 pin 所依赖的完整基线。
- 修复 PowerShell 字符串包装及对象属性顺序导致的身份不稳定、单文件集合退化、空缓存/空 target 大小计算错误；格式文件清单纳入缓存身份，扩大检查范围时不能复用较小范围的结果。
