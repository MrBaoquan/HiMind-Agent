## 读取、缓存及启动边界

- 搜索任务缓存项目元数据快照和分页进度，不建立持久全文索引，也不把正文写入登记表。每页仍通过原来源接口校验当前项目归属。
- 每批最多两页，批次在完成一页后检查耗时与取消。底层正在读取的一页不能被中途抢占；取消后前端立即停止等待并丢弃迟到结果。
- 每个任务最多 2,000 个会话、2,000 页、500 个结果、64 MiB 已解析文字/文件记录；同时最多 8 个任务，5 分钟后过期。达到上限明确标为结果不完整，不将限额当作无匹配。
- Claude/Codex 的来源路径解析使用最多 2,048 项、5 秒的元数据缓存。按来源根、来源、项目和原生 ID 隔离；文件大小/mtime 变化、路径失效立即淘汰。缓存命中后仍重新读取会话元数据、校验身份与归属，正文不缓存。相同 ID 出现新副本时，路径选择最多有 5 秒延迟。
- 单个文件操作的内容最多展示 16,384 个字符；每条消息最多 64 项文件记录，单个 MultiEdit 最多 32 项。内容或条目截断有显式提示，正文检索遇到截断记录也报告部分读取。不是完整文件快照或当前 Git diff。
- 现有来源限制继续生效：JSONL 文件 64 MiB、单行 2 MiB、每页扫描 8 MiB；ACP/OpenCode 沿用各自预算。DSH 使用 Runtime 接口，未扫描其私有存储。
- 恢复 ID 限定字母、数字、连字符和下划线，首字符必须为字母或数字、最多 128 字节；其他合法历史 ID 仍可预览，只是不允许 CLI 恢复。
- Windows 启动采用固定系统 PowerShell、UTF-16 编码脚本与单引号字面量，优先原生 exe 或 ps1 shim，避免嵌套 cmd 解析。目标目录和客户端来自后端，移除宿主密钥环境变量；同一会话 5 秒内抑制重复启动。成功提示表示终端已启动，CLI 后续结果在终端中显示。
- 非 Windows 原生终端、仅有 cmd shim、WSL、多账号/多来源根、任意 Shell 文件修改重建、文件覆盖恢复、导出归档及实时文件监听未包含在本阶段。
