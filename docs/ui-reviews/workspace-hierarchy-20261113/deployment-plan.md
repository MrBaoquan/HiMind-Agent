## 已准备的操作

使用已编译的 `target/workspace-hierarchy-candidate/release/` 候选，替换当前 HiMind Agent 的主程序、MCP 和 launcher 三个程序，并重启 Agent。三个程序版本均为 0.3.92，版本号不变；通过 SHA-256 区分新版。停止和重启会短暂中断 Agent/MCP。

候选来自当前工作树，包含已有未提交改动，不是仅包含本任务的独立发布分支。[精确部署清单](evidence/deployment-plan.json)列出源、目标、候选与现有安装指纹、已验证备份和恢复规则。

1. 停止前重新核对候选、现有安装、备份及 active-version 的指纹；任一文件变化即停止本次部署，重新评估差异。
2. 仅停止已确认属于本机 HiMind 安装的相关进程，复制清单中的三个程序；同版本 active-version 不需要修改。
3. 使用现有状态文件位置启动主程序，检查 18181 健康接口命中新 PID、实际执行路径及安装文件指纹。
4. 复制或健康检查失败时，恢复已验证的旧程序备份并重启旧版，记录实际结果。

Runtime 固定包与真实工作区登记保持现状；IODevice 的父子项目和中文命名提案不随部署自动应用。不会运行会重新编译及处理 Runtime 的通用 `deploy-local.ps1`。
