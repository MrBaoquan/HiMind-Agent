## 架构边界与配置事实源

```text
服务编辑/导入 → 配置唯一写所有者
  ai-services: 服务账号/加密凭据/endpoints/模型目录
  selection: capability_routes 有序服务+模型偏好
      → 客户端投影（本机URL/token，不是上游Key）
      → 环回网关：授权→路由→协议适配→响应/公共错误
      → 安全请求台账(request_id, config版本, transport结果)
Mission指派(专家版本/执行器/服务模型) → Runtime适配器 → 执行进程
      → run usage/事件 → 预算门控 → 等待/审批后继续
      → 共享只读状态投影 → 列表/详情/待处理
```

服务是连接账号，不是模型进程；endpoints 为连接事实源，旧标量仅兼容投影。路由的首选/备用不复制成第二份服务默认；客户端分发是可重建投影，应标配置版本、同步版本及差异，冲突人工确认。工作台服务归工作台所有者，本机只能展示允许编辑范围；本机服务定义与左栏本机进程管理须解释区别。执行器管理进程、工作目录、事件和用量，专家表达职责与版本，不提升权限。业务授权不等于OS沙箱。

默认来源分别展示：服务默认、能力路由模型覆盖、客户端自身配置、远程任务默认执行器、任务显式指派。已有agentApi:3585-3604支持空模型跟随及resolved/ambiguous/missing；无解析证据显示未解析，不能推断全局默认会重配已有任务。后端负责人须补优先级决策表和请求测试后才能给UI“最终选择”。

网关候选切换范围按当前同Provider/同上游模型/同协议边界说明，不承诺任意跨模型自动降级。流已写出不无缝重放，避免工具调用副作用重复。公共错误只输出安全code/request_id/限长脱敏说明，观测不记Key/完整请求。请求台账与Mission预算不同层，新增关联id和完整性而不双算费用；混币拒绝比较，未知不填零；续跑保留request_id幂等、计划哈希、waiting及无运行任务检查。

## 信息层级与核心路径

导航保留：我的任务→全部/待我处理/进行中/已结束→概览/计划/专家/活动；设置→AI连接→工具接入/AI服务/模型网关/能力路由/运行环境。待处理是任务同一事实的聚合，不另存状态。首屏任务稳定显示阶段、原因、行动者、下一步、新鲜度，进度是已核验子任务计数不是耗时百分比。

- 首次接入：新增服务连接/凭据→能力模型→保存定义→能力路由默认备用→工具接入更新→用户明确自检。每步区分保存、同步、请求验证；自检提示可能消费费用，失败保留非秘密输入。
- 改默认：路由中选服务与跟随/固定模型→核对作用域→同步需要更新客户端→任务显式指派核对；不静默改已有任务。
- 等待恢复：待我处理→读取同快照原因与动作资格→已支持新契约且资格允许才提交显式预算扩展→以后端返回及刷新确认 active 或环境仍 waiting。旧后端遇 budget_exhausted→task_progress 必然拒绝新扩展，不能描述为已打通；只读诊断/受控重检见 B08 跨层决策。主动暂停另列，系统核验无需用户操作；未知原因只进详情。
- 查证据：任何总体状态，只要子任务提交证据即可概览/行内查看；实现、必需检查、独立核验分开。没有正文写未提供；重核/重做/续跑说明重复范围。

prototype.html 是内联CSS/JS、系统字体、虚构example.invalid数据、页面内存交互，不联网/不持久化。演示工具可用+待更新、服务→模型、执行器独立指派、任务预算/环境/核验等待及部分结果；服务区可切加载/空/错/部分可用/成功/无权限，支持筛选空与清除、原生dialog、radio和名称错误定位。没有真实密钥输入，不实现完整业务向导/协议校验/真实预算授权。执行器与模型不是上下级所有权，明确“执行器使用指派的服务模型或自身配置”。无权限仅示意，实际权限模型需产品确认。
